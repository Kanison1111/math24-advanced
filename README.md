## เปิดเกม

เป็นเว็บ static ไม่ต้อง build หรือติดตั้ง dependency สำหรับตัวเกม:

```sh
python3 -m http.server 8000
```

## ทดสอบอัตโนมัติ

ใช้ Python 3.10+ และ unittest ใน standard library ร่วมกับ Playwright สำหรับทดสอบ JavaScript จริงใน Chromium โดยไม่เพิ่ม framework ให้ตัวเกม:

```sh
python3 -m venv /tmp/math24-test-venv
/tmp/math24-test-venv/bin/pip install -r requirements-test.txt
/tmp/math24-test-venv/bin/python -m playwright install chromium
/tmp/math24-test-venv/bin/python -B -m unittest discover -s tests -v
```

หากมี Chromium อยู่แล้ว สามารถข้ามการดาวน์โหลด browser และกำหนด `CHROMIUM_PATH` เป็น path ของ executable เช่น:

```sh
CHROMIUM_PATH=/usr/bin/chromium python3 -B -m unittest discover -s tests -v
```

ชุดทดสอบเปิดเซิร์ฟเวอร์เฉพาะเครื่องบนพอร์ตว่างเองและปิดหลังจบ แต่ละ test ใช้ browser context ใหม่เพื่อแยก localStorage และใช้ virtual clock ไม่ต้องรอเวลาจริง ครอบคลุม parser/เศษส่วน/ลำดับคำนวณ, √ ! ^, เลขติดลบ, สูตรผิด, คะแนนและขอบเขตโบนัสเวลา, ค่าคำใบ้และจำนวนครั้ง, คะแนนซ้ำ/ดูเฉลย, เวลาฝึกซ้อม, การยุติ/หมดเวลา/ครบ 10 ข้อ, คะแนนฝึกซ้อมแยกการแข่งขัน และหน้าเว็บที่ 360/1280 px

## V1.0 ระยะแรก · Multiplayer UI Prototype

เปิด `multiplayer.html` หรือกดลิงก์ Multiplayer บนหน้าเกม มีหน้าสร้างห้อง,
เข้าร่วม, ห้องรอ และ Ranking ธีมขาวดำ รองรับมือถือและ GitHub Pages ใต้ subpath
ใช้ HTML/CSS/JavaScript ธรรมดา ไม่ต้อง build

**เป็นข้อมูลจำลองทั้งหมด** ไม่มี Supabase, ผู้เล่นจริง, การส่งคำตอบ หรือการแข่งขัน
หลายคนจริง ข้อมูลอยู่ในหน่วยความจำและล้างเมื่อรีเฟรช หน้าเกมเดิมยังเล่นฝึกซ้อมและ
แข่งขันคนเดียวได้ตามเดิม ไม่เปลี่ยน Parser, Solver, คะแนน หรือกติกาเดิม

- สร้างห้อง: 5/10/15/20 ข้อ, เวลา 1–120 นาที, พื้นฐาน/ขั้นสูง,
  ง่าย/ปานกลาง/ยาก หรือผสมโดยผลรวมต้องเท่าจำนวนโจทย์, Ranking สด/หลังจบ
- เข้าห้องตัวอย่าง `240024`; รหัส `111111` จำลองห้องเต็ม,
  `000000` จำลองห้องปิด, รหัสอื่นจำลองไม่พบห้อง
- เปิด “เครื่องมือสาธิต” ในห้องรอเพื่อสลับความพร้อมและจำลองหลุด/เชื่อมต่อใหม่
  ครูเริ่มได้เมื่อทุกคนพร้อม ผู้เล่นใช้ปุ่มจำลองครูเริ่มแข่งขัน
- หน้า Ranking ใช้ผลคะแนนตัวอย่างคงที่ ไม่มีการคำนวณคะแนนใหม่
  เลือกดูทั้งหมด/เฉพาะฉัน ทดลอง loading/empty/error และลองโหลดใหม่ได้
  แบบหลังจบซ่อนข้อมูลจนกดจำลองจบการแข่งขัน
- กลับห้องรอเพื่อทดลองรอบใหม่ หรือออกจากห้องผ่านหน้าต่างยืนยัน
